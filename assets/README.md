# MIRA brand assets

The approved MIRA identity uses the following palette:

| Role | Hex |
| --- | --- |
| Owl body | `#3489CA` |
| Eyes and capsule top | `#AED0EA` |
| Pupils and wordmark | `#173B59` |

## Brand files

- `brand/mira-logo.svg` — editable horizontal logo for websites and print.
- `brand/mira-owl.svg` — editable standalone mark for avatars and icons.
- `brand/mira-logo-1200.png` — transparent raster logo used by the project README.

Use the full logo on white or light backgrounds and preserve its aspect ratio and
clear space. Use the standalone owl at small or square sizes.

## Website icons

The `favicon/` directory contains the SVG and ICO favicons, PNG fallbacks, Apple
touch icon, Android/PWA icons, and web manifest. The manifest assumes all favicon
files are served from the same directory.
